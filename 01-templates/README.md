# Templates

**Audience:** anyone drafting a new funding application for Anamata Kāhui.

## What's in this folder

- `boilerplate.md` — canonical organisation bio, multi-iwi context, naming-origin, framing line, one-liner. Reusable across all rounds.
- `style-guide.md` — voice, framing line, two-pillar pattern, three-phase arc, budget pattern, concrete-specificity rule, People & Organisations pattern, closing whakataukī. Synthesised from the 2026 CNZ win.

## How to use these templates

Every new application draft should:

1. **Read `boilerplate.md` first.** Identify which sections are reusable as-is (e.g., organisation one-liner, naming origin) vs which need adaptation (e.g., the standing bio's role label changes depending on the round's audience).
2. **Read `style-guide.md` next.** Identify which patterns fit the round's question shape:
   - Capability / development rounds → use the **two-pillar pattern + three-phase arc**
   - Production / project rounds → use the **single deliverable + named budget + audience reach plan**
   - Research / methodology rounds → use the **problem-statement + methodology paper + evidence surface** pattern
3. **Read the round-specific template** (if one exists in `past-applications/<round>/`) for the proven question-by-question structure.
4. **Draft using the patterns as scaffolding** — never copy-paste-final. Each application must be re-read in its own context.

## What is NOT a template

The two past applications in `02-past-applications/` are **examples**, not templates. Each was drafted for a specific round's question shape. Don't transplant CNZ text into NZ On Air applications or vice versa — the question framing differs.
