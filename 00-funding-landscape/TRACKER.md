## How the cron uses this file

The funding cron reads this file every Monday and:

1. Checks the open dates of every round listed above.
2. For rounds that are **currently open**, runs an eligibility check
   against the snapshot at the top of this file.
3. Reports back to Telegram: open rounds, eligibility verdict, and
   anything blocking submission.
4. When a round's deadline is **within 14 days**, escalates.
5. When a round **closes without being submitted**, flags the missed
   opportunity and asks if you want to plan for the next round.

## Updating

If Fin's situation changes (new entity type, new releases, co-funding
secured, cultural reviewer confirmed), update the **Eligibility
snapshot** at the top. The cron reads that section first.
