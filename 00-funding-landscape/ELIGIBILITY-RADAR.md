## How the cron refreshes this file

The `5782145d9c5f` funding cron runs Mondays 09:00 NZT and:

1. Reads `funding/TRACKER.md`.
2. Pulls the round table for each funding body listed above.
3. Cross-references each round against the eligibility snapshot.
